## 3.1. Наследование

Новый класс создаётся на базе существующего. Наследник получает
поля и методы родителя и может их расширять. Отношение «является»
(is-a): `Dog` **является** `Animal`.

```cpp
class Animal {
public:
    void eat() const { std::cout << "eating\n"; }
};

class Dog : public Animal {     // public-наследование: is-a
public:
    void bark() const { std::cout << "woof\n"; }
};

int main() {
    Dog d;
    d.eat();    // унаследовано
    d.bark();   // своё
}
```

Типы наследования:

- **`public`** — интерфейс родителя остаётся публичным. Обычный случай
  для отношения is-a.
- **`protected` / `private`** — меняют видимость унаследованных членов;
  на практике нужны редко, в этом курсе не используются.

Что наследуется: все поля и методы, кроме конструкторов, деструкторов
и `operator=`. Их наследник должен вызывать/определять сам.

Пример: `inheritance.cpp`.

## 3.2. Полиморфизм

Возможность работать с объектами разных классов через единый
интерфейс базового класса, а конкретная реализация выбирается
**во время выполнения** — по реальному типу объекта.

Работает через **виртуальные функции**:

```cpp
class Animal {
public:
    virtual void speak() const { std::cout << "...\n"; }
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void speak() const override { std::cout << "Woof\n"; }
};

class Cat : public Animal {
public:
    void speak() const override { std::cout << "Meow\n"; }
};

void makeSound(const Animal& a) { a.speak(); }   // выбор в рантайме

int main() {
    Dog d;
    Cat c;
    makeSound(d);   // Woof
    makeSound(c);   // Meow
}
```

Ключевые слова:

- **`virtual`** — объявляет метод переопределяемым. Включает
  динамическое связывание.
- **`override`** — подсказка компилятору: «я переопределяю виртуальный
  метод родителя». Если сигнатуры не совпадут — ошибка компиляции.
- **`virtual ~Animal()`** — виртуальный деструктор. **Обязателен**,
  если через указатель на базовый класс удаляют наследника; иначе
  деструктор наследника не вызовется (утечка).

Пример: `polymorphism.cpp`.

## 3.3. Абстрактные классы

Если метод помечен `= 0`, он **чисто виртуальный**: реализации нет,
наследники обязаны её дать.

Класс, содержащий хотя бы один чисто виртуальный метод, называется
**абстрактным**. Экземпляр такого класса создать нельзя — он
описывает только интерфейс.

```cpp
class Shape {
public:
    virtual double area() const = 0;      // чисто виртуальный
    virtual ~Shape() = default;
};

class Circle : public Shape {
    double r_;
public:
    explicit Circle(double r) : r_(r) {}
    double area() const override { return 3.14159 * r_ * r_; }
};

int main() {
    // Shape s;                    // ошибка: абстрактный
    Circle c(2);
    std::cout << c.area();         // OK
}
```

Абстрактный класс — это интерфейс: он говорит, *что* должны уметь
наследники, не навязывая *как*.

Пример: `polymorphism.cpp` (вторая часть).
