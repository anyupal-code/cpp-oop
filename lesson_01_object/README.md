## 1.1. `struct` и `class`

**Структура (`struct`)** — пользовательский тип, объединяющий данные.
Все поля `public` по умолчанию. Для пассивных наборов данных.

**Класс (`class`)** — объединяет данные и методы.
Все поля `private` по умолчанию. Для объектов с логикой.

**Разница** — только в уровне доступа по умолчанию.
Технически `class` и `struct` — одно и то же.

```cpp
struct Point { int x, y; };                    // public по умолчанию
class  Player { int hp; public: void hit(); }; // private по умолчанию
```

Пример: `struct_vs_class.cpp`.

## 1.2. Инкапсуляция

Сокрытие внутреннего состояния. Данные — `private`.
Доступ — через `public` методы (геттеры/сеттеры).
Защищает объект от некорректного изменения извне.

```cpp
class Account {
    double balance = 0;
public:
    void deposit(double sum) { if (sum > 0) balance += sum; } // валидация внутри
    double get() const { return balance; }
};
```

Пример: `encapsulation.cpp`.

## 1.3. Конструктор и деструктор

**Конструктор** — вызывается при создании, инициализирует поля.
**Деструктор** — вызывается при уничтожении, освобождает ресурсы.

```cpp
class Point {
    int x, y;
public:
    Point(int x, int y) : x(x), y(y) {}  // конструктор с параметрами
    ~Point() {}                          // деструктор
};
```

Пример: `ctor_dtor.cpp`.

## 1.4. Передача по ссылке и копирование

Объекты нельзя передавать по значению без последствий (дорого).
Используем ссылки:
* `T&` — изменение объекта.
* `const T&` — чтение без копирования.

```cpp
void move(Point& p);        // изменение
void print(const Point& p); // только чтение
```

Пример: `passing.cpp`.

## 1.5. Перегрузка операторов

Можно определить, что значат `+`, `==`, `<<` и другие операторы
для вашего типа. Синтаксис вызова остаётся обычным: `a + b`, `a == b`,
`std::cout << a`.

Два способа объявить оператор:

- **член класса** — когда левый операнд вашего типа (например, `Point::operator+`);
- **свободная функция** — когда левый операнд чужого типа
  (например, `std::ostream& operator<<(std::ostream&, const Point&)`).

```cpp
struct Point {
    int x, y;

    Point operator+(const Point& o) const { return {x + o.x, y + o.y}; }
    bool  operator==(const Point& o) const { return x == o.x && y == o.y; }
};

// свободная функция: левый операнд — std::ostream, не Point
std::ostream& operator<<(std::ostream& os, const Point& p) {
    return os << "(" << p.x << "," << p.y << ")";
}
```

Использование — как у встроенных типов:

```cpp
Point a{1, 2}, b{3, 4};
std::cout << (a + b);   // (4,6)
bool same = (a == b);   // false
```

Пример: `operators.cpp`.
